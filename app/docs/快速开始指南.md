# 快速开始指南

本指南将帮助你快速启动并测试卡密授权系统。

---

## 📋 前置条件

1. **Python 3.9+** 已安装
2. **MySQL 5.7+** 已安装并运行
3. **pip** 包管理器已安装

---

## 🚀 快速启动（5步）

### 步骤 1：安装依赖

```bash
pip install -r requirements.txt
```

### 步骤 2：配置数据库

编辑 `.env.development` 文件，设置你的数据库信息：

```bash
DB_USER=root
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=3306
DB_NAME=login_km_system_dev
```

### 步骤 3：创建数据库

```bash
# 设置开发环境
export ENV=dev

# 创建数据库
python -m app.scripts.create_database
```

### 步骤 4：应用数据库迁移

```bash
# 应用迁移（创建表结构）
alembic upgrade head
```

如果 `alembic` 命令不可用，使用：
```bash
python -m alembic upgrade head
```

如果你接入的是已有业务表的老数据库，且之前没有正确维护 `alembic_version`，不要直接执行 `upgrade head`。

典型现象是报错：

```text
Table 'apps' already exists
```

这说明 Alembic 把你的数据库误判成了空库。此时应先 `stamp` 到真实版本，再继续升级。例如：

```bash
ENV=development ./venv/bin/python -m alembic stamp 003_fix_fp_id_ai
ENV=development ./venv/bin/python -m alembic upgrade head
ENV=development ./venv/bin/python app/scripts/upgrade_feature_permissions_app_binding.py
```

这组命令适用于：

- 已经存在 `apps`、`cards`、`feature_permissions` 等业务表
- 但数据库中还没有 `feature_permissions.app_id`
- 同时缺失正确的 Alembic 版本记录

### 步骤 5：初始化系统数据

```bash
# 创建默认应用和管理员账户
python -m app.scripts.init_data
```

执行成功后会看到：
```

====================================================
```

## 🧪 快速测试

### 方法一：使用 Swagger UI（推荐）

1. 打开浏览器访问: http://localhost:8003/docs

2. **测试用户登录**：
   - 找到 `POST /api/v1/auth/login`
   - 点击 "Try it out"
   - 输入以下内容：
     ```json
     {
       "username": "testuser",
       "password": "test123456",
       "app_key": "default_app",
       "device_id": "test-device-001"
     }
     ```
   - 点击 "Execute"
   - 复制返回的 `token`

3. **设置认证Token**：
   - 点击页面右上角的 🔒 "Authorize" 按钮
   - 在弹出窗口中输入: `Bearer <你的token>`
   - 点击 "Authorize"
   - 点击 "Close"

4. **测试需要认证的接口**：
   - 找到 `GET /api/v1/auth/me`
   - 点击 "Try it out"
   - 点击 "Execute"
   - 应该返回当前用户信息

### 方法二：使用 curl 命令

#### 1. 用户注册
```bash
curl -X POST "http://localhost:8003/api/v1/auth/register" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "myuser",
    "password": "mypassword123"
  }'
```

#### 2. 用户登录
```bash
curl -X POST "http://localhost:8003/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "testuser",
    "password": "test123456",
    "app_key": "default_app",
    "device_id": "test-device-001"
  }'
```

保存返回的 `token`，例如：
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user_status": "normal",
  "has_card": false,
  "username": "testuser",
  "role": "user"
}
```

#### 3. 验证Token
```bash
curl -X GET "http://localhost:8003/api/v1/auth/verify" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"
```

#### 4. 获取当前用户信息
```bash
curl -X GET "http://localhost:8003/api/v1/auth/me" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"
```

## 🔧 常见问题

### Q1: 数据库连接失败
**错误**: `sqlalchemy数据库连接失败`

**解决**:
1. 检查 MySQL 服务是否运行
2. 检查 `.env.development` 中的数据库配置
3. 确保数据库用户有权限创建数据库

### Q2: alembic 命令找不到
**错误**: `command not found: alembic`

**解决**:
使用完整的 Python 模块调用：
```bash
python -m alembic upgrade head
```

### Q3: Token 验证失败
**错误**: `Token无效` 或 `Token已过期`

**解决**:
1. 检查Token是否正确复制（包括完整内容）
2. 检查是否使用了 `Bearer ` 前缀
3. Token默认有效期7天，过期需要重新登录

### Q4: 密码验证失败
**错误**: `用户名或密码错误`

**解决**:
1. 确认密码至少6位
2. 确认用户名存在
3. 默认测试账户：`testuser` / `test123456`

### Q5: 应用不存在
**错误**: `应用不存在`

**解决**:
1. 确认使用了正确的 `app_key`
2. 默认应用标识是：`default_app`
3. 运行初始化脚本：`python -m app.scripts.init_data`

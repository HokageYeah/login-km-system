# 阶段五：管理后台功能 - 测试指南

## 📋 测试准备

### 1. 创建管理员用户

```bash
cd /Users/yuye/YeahWork/Python项目/login-km-system
source venv/bin/activate
python app/scripts/create_admin_user.py
```

默认管理员账号:
- 用户名: `admin`
- 密码: `admin123`

你也可以自定义用户名和密码:
```bash
python app/scripts/create_admin_user.py myAdmin myPassword123
```

### 2. 启动服务器

```bash
python run_app.py
```

服务器将在 `http://localhost:9999` 启动

### 3. 获取管理员 Token

首先使用管理员账号登录获取 Token:

```bash
curl -X POST http://localhost:9999/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "admin",
    "password": "admin123",
    "app_key": "wx_crawler_app",
    "device_id": "admin_device_001"
  }'
```

保存返回的 `token` 字段值,后续所有管理接口都需要使用此 Token。

## ✅ 任务 16：管理后台查询接口

### 16.1 查询所有用户

```bash
# 基础查询
curl -X GET "http://localhost:9999/api/v1/admin/users?page=1&size=10" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"

# 按状态筛选

  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"

```

**预期结果**:
- 返回用户列表
- 包含用户ID、用户名、状态、角色、卡密数量等信息

**封禁用户**:
```bash

  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"
```

**解封用户**:
```bash
curl -X POST "http://localhost:9999/api/v1/admin/user/3/status?status=normal" \
  -H "Authorization: Bearer YOUR_ADMIN_TOKEN"
```

**验证**:

- 被封禁的用户权限校验失败
- 解封后恢复正常

## ⚠️ 注意事项

1. **管理员权限**
   - 所有管理接口都需要管理员权限
   - 普通用户访问会返回 403 错误

2. **实时生效**
   - 卡密权限修改立即生效

   - 无需重启服务器

3. **数据安全**
   - 管理员操作都有日志记录
   - 敏感操作需要验证管理员 Token

4. **性能优化**
   - 列表查询支持分页
   - 大数据量时建议使用筛选条件

## 🐛 常见问题

### 1. 管理员登录失败

**问题**: 使用 admin 账号登录返回 "用户名或密码错误"

**解决**:
```bash
# 重新创建管理员用户
python app/scripts/create_admin_user.py
```

### 2. 权限验证失败

**问题**: 管理员 Token 访问管理接口返回 403

**解决**:
- 检查 Token 是否过期
- 检查用户角色是否为 admin
- 重新登录获取新 Token

### 3. 卡密生成失败

**问题**: 生成卡密时返回 "应用不存在"

**解决**:
- 检查 `app_id` 是否正确
- 确认应用状态为 normal
